# README Release Notices Design

## Scope

Add two prominent notices to both `README.md` and `README.zh-CN.md`:

1. M5Launcher users must install the Beta Release.
2. Users are encouraged to use Cardputer Codex Companion together with
   [Type4Me](https://github.com/joewongjc/type4me).

No firmware, installer, release artifact, or runtime behavior changes are in
scope.

## Placement and presentation

Place a compact bold notice block immediately below the current release line
near the top of each README. This makes both constraints visible before readers
choose an installation path.

Use natural English in `README.md` and equivalent Chinese wording in
`README.zh-CN.md`. Keep “Beta Release” bold and preserve Type4Me as a direct
Markdown link.

## Verification

- Confirm both README files contain the two notices.
- Confirm the Type4Me URL is identical in both files.
- Confirm Markdown emphasis and links are syntactically valid.
- Confirm no unrelated tracked files are modified.
