# Cardputer UI、输入隔离与 Settings 保存修复设计

日期：2026-07-26

## 目标

修复状态页首行偏移、DEVICE 页 PIN 掩码、非宠物页输入泄漏到 HID，以及 Settings 页面操作和保存失败问题。保持现有配置格式和 Web/API 兼容性。

## 页面显示

- 所有状态页正文从屏幕左边界 `x=0` 开始，首行与后续行对齐。
- DEVICE 页按 Version、PIN、BLE、Wi-Fi、Agent 展示。
- DEVICE 页显示设备当前真实 PIN；Web 登录页的 PIN 输入掩码逻辑不受影响。

## 输入边界

- 只有 PET 页面允许普通按键、组合键或字符串动作进入 HID/宏输出路径。
- DEVICE、CODEX、SYNC、SETTINGS 页面消费所有键盘事件，不向 BLE HID 或 Mac agent 发送输入。
- 从 PET 离开时主动清空 HID 报告；切回 PET 后仅处理新的按键事件，不重放切页期间按下的键。
- 配对流程保留在页面输入隔离之前，确保需要时仍能完成 BLE 配对。

## Settings 交互

- `;`：向上选择。
- `.`：向下选择。
- `,`：减小数值或选择上一个值。
- `/`：增大数值或选择下一个值。
- Enter：进入、确认或保存。
- 反引号：取消或返回；位于 Settings 根菜单时返回 PET。
- 文本编辑状态接受普通可打印字符；Enter 保存，反引号取消，Backspace 删除。
- Settings 菜单支持滚动，当前项始终保持可见。

## 保存事务

- Settings 菜单生成包含完整值快照的类型化命令，不在菜单层提前把未持久化值当作成功状态。
- 控制器串行执行 Profile、PIN、Wi-Fi 和设备显示设置的持久化。
- 仅在持久化成功后更新运行时状态和 UI；失败时保留编辑上下文，显示具体配置项的失败结果。
- 串口日志包含命令类型和底层错误码，但不输出 PIN、Wi-Fi 密码或其他敏感值。
- 沿用现有存储后端与键名，不进行配置迁移。

## 验证边界

- 主机测试覆盖首行布局参数、真实 PIN、页面级 HID 放行策略、Settings 全部按键语义、返回 PET、命令快照与成功/失败状态。
- 固件完整编译并生成可刷写产物。
- 刷入当前连接的 Cardputer，通过串口确认无重启循环和保存错误。
- 真机逐页验证非 PET 页面无 HID 输出，PET 页面仍能正常输入；逐项验证 Profile、PIN、Wi-Fi、Brightness、Return、Pet FPS 保存。

## 非目标

- 不修改 Web 登录页的 PIN 掩码。
- 不改变 BLE 配对、安全策略或现有键盘 profile 数据格式。
- 不迁移到新的 NVS 分区或重置用户已有配置。
